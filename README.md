# El-mundial-para-dummies

Este es un proyecto web educativo e interactivo de infografía sobre el Mundial del futbol, es principalmente una simulación.  
Incluye inicio de sesión, registro, infografías de distinto mundiales, publicaciones, perfil, preferencias de accesibilidad, onboarding y dashboard personalizado.

---

## Objetivo
Crear una plataforma amigable y accesible donde cualquier usuario pueda aprender sobre los Mundiales, ver publicaciones y personalizar su experiencia.

---

## Funcionalidades principales

### Sistema de usuarios (auth.js)
- Registro con validación de edad mínima
- Inicio de sesión
- Roles: lector y administrador
- Logout
- Persistencia en localStorage

### Publicaciones
- Aprobar/Rechazar publicaciones (solo admin)
- Crear publicaciones
- Filtrar por autor
- Likes / dislikes
- Guardado en localStorage

### Accesibilidad
- Aumentar/disminuir tamaño de letra
- Contraste alto
- Fuente para dislexia
- Línea de lectura
- Tema oscuro/claro

### Onboarding interactivo
Explica:
- Cómo navegar la página principal
- Cómo usar buscador y filtros en Mundiales
- Cómo publicar/filtrar en Publicaciones

### Dashboard (perfil.js)
- Muestra estadísticas de:
  - Publicaciones creadas
  - Likes/dislikes dados
  - Tema actual
  - Preferencias activas

---

## Perfil del usuario
El usuario puede:
- Ver sus datos personales
- Subir foto de perfil
- Ver publicaciones propias
- Ajustar preferencias de accesibilidad
- Ver su dashboard de estadísticas
